# Ghost in the Loop 8.8.6 — Android / Firefox physical canary

This is the final real-device check for the isolated 8.8.6 candidate. It is not a release installer and it must not replace the public 8.8.5 `main` install.

## Setup

1. On Firefox for Android, install **Tampermonkey** or **Violentmonkey** from Firefox's Android add-ons catalog.
2. Import the exact `ghost-in-the-loop.user.js` bytes from the certified `candidate/8.8.6-host-lifecycle-hardening` commit named in the certification record.
3. Open a new ChatGPT conversation. Repeat the same sequence in Perplexity.

## One-pass canary

For each host:

1. Confirm Ghost reports version 8.8.6 and the normal Auto / Alpha / Beta / Gamma / Delta controls are present.
2. Run Auto for rounds 1, 2, 8, 16, and 24 in the same long conversation. Each requested round must produce **exactly one** submitted message.
3. Between two known-not-sent rounds, navigate away and back without closing Firefox, then continue. Ghost must reacquire the live composer without duplicating its UI or staging text twice.
4. In a fresh conversation, exercise Alpha, Beta, and Gamma once each. They must remain distinct dispatch routes. Exercise Delta only as the manual fallback.
5. On Perplexity, visually confirm the intended text appears once before submission. Any duplicated staging is a failure.
6. If Ghost reports a pre-dispatch lifecycle failure, capture the redacted diagnostic stage/code and use Resume only when Ghost explicitly says the attempt is known-not-sent.

## Absolute stop rule

If a Send actuator may have fired, delivery is ambiguous, or a message appears to have been submitted, **do not press Resume and do not try another route for that attempt**. Stop the canary and preserve the diagnostic report. This protects the 8.8.5 at-most-once invariant.

## Pass / fail

PASS only if both ChatGPT and Perplexity complete the sequence with no duplicate staging, duplicate messages, stale-composer dispatch, duplicated Ghost UI, or ambiguous automatic retry.

FAIL on the first violation. Record host, round, selected route, lifecycle failure stage/code, and whether the message was visibly submitted. Do not include prompt text, URLs, conversation IDs, or other private content.

## Why physical Firefox remains a gate

Desktop Playwright Firefox is valuable but is not Firefox for Android. The physical canary is therefore the final evidence for Android/Fenix-specific lifecycle behavior.
