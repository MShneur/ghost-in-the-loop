# Ghost 9.0.0-alpha.2 — Final Lens Review

Date: 2026-09-14
Branch: `rewrite/9.0.0-core-activators`
Authority: repository evidence + current Firefox-Android/Perplexity field failures.

## Cleanerz adapter

DONE = root userscript contains the new Play + Export architecture, syntax checks, and is ready for a bounded phone field run.

BROKEN = Play still depends on roadmap/persona/controller reasoning, selects a transport whose own prerequisites are false, sends twice after uncertainty, or cannot explain a transport failure without reading task content.

Loop identified: 8.8.x accumulated recovery layers around a transport/controller boundary that was already wrong. Fixes began fixing previous fixes. The new direction keeps the AI as the reasoner and Ghost as a mechanical relay.

## Independent lenses

### 1. Browser / DOM reliability

P0 found: composer verification was byte/line-format sensitive and allowed only ~100 ms for Lexical reconciliation. Prior field evidence already showed visible correct text being rejected.

Resolution: verification now compares semantic visible text and reacquires/polls the current composer for up to 1.8 s.

P0 found: Send was resolved once immediately after injection. A framework rerender or delayed enablement could produce a false `Send missing` while the visible host button existed.

Resolution: reacquire the current local host Send control for up to 2.2 s before failing. Still one actuator and one click; no Enter/requestSubmit fallback chain.

### 2. State machine / duplicate-send safety

P0 found: stale assistant output could be reprocessed after a confirmed send.

Resolution: each send binds the previous assistant hash and waits for a changed answer before terminal handling resumes.

Safety retained: after one click, unconfirmed acceptance sets `uncertain` and pauses. There is no automatic resend.

### 3. Protocol-contract lens

P0 found: alpha.1 said the terminal must be exact while examples showed `[[...]] -- explanation`. The parser accepted only the bare marker.

Resolution: alpha.2 shows the meaning on one line and the exact bare marker on the next, explicitly forbidding text before/after the final marker.

### 4. Completion / drift lens

P0 found: two stable polls could treat a temporary streaming stall as a finished answer if the Stop selector was momentarily absent, then inject a reground message into an answer still being generated.

Resolution: a valid exact terminal can act after a short stability window, but a missing/invalid terminal must remain unchanged and non-generating for 9 seconds before drift recovery fires.

P0 found: pressing Play on an existing non-Ghost conversation could accuse the model of protocol drift before the protocol had ever been armed.

Resolution: first Play on an existing chat without a terminal sends one bootstrap/arming continuation. Drift logic starts only after that.

### 5. Adapter locality / Red Team lens

Historical Round-6 worker evidence showed global-first-editor inference misselected decoys while adapter-owned scoped identity avoided those fixture failures. That lesson is preserved.

Resolution: Perplexity now uses only the field-observed `#ask-input` editor, exact `button[aria-label="Submit"]`, and `[data-workflow-final-text]` assistant output. The broad `div[class*=prose]` fallback was removed. ChatGPT keeps its reviewed role-based message nodes and send controls. Other hosts remain generic/best-effort and do not gain special authority.

### 6. Product / complexity lens

P0 architectural issue: alpha.1 fetched and inlined full external protocol files into prompts, making Ghost responsible for protocol transport, cache behavior, prompt bloat, and potential terminal-contract collisions.

Resolution: activators are pointer-first only. Ghost names the canonical source. The active AI/runtime retrieves/applies it when capable. AoA, CTRL-AI, and R-Duck stay external systems. A custom AoA path remains available.

The production candidate now lives at the normal root `ghost-in-the-loop.user.js`; the temporary `/v9/` install path was removed.

## Export lens

Export remains independent of Play.

- ChatGPT: attempts `/backend-api/conversation/{id}` and parses supported user/assistant turns.
- Perplexity: attempts `/rest/thread/{slug}` and preserves the raw response; until that shape is validated, rendered turns are labeled partial.
- DOM-only capture is always labeled partial.

No export failure can change Play state.
