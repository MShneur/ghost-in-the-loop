## Item 1 — reliable Perplexity answer selection

Status: implemented and unit-verified.

- Separates Perplexity's broad `.pb-md > div` selector into a fallback tier.
- Restores actual document order across selector groups.
- Bounds each selector scan to the newest 48 matches.
- Ignores disconnected, hidden, empty, navigation, toolbar, and follow-up candidates.
- Anchors on the newest answer before considering a terminal marker, so an older HALT cannot beat a newer unfinished response.
- Resolves nested answer nodes within the newest answer cluster and retains the complete answer text.
- Does not modify Send, retry, or actuator authority.

Regression coverage includes current HALT plus later follow-up UI, primary-selector follow-ups, hidden duplicates, broad fallback use, nested marker nodes, and the older-HALT/newer-streaming boundary.
